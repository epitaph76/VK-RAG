## Корпус и разметка

23 реальные статьи: 8 Хабр, 15 N+1; 138 чанков по 384 E5-токена с перекрытием 64. SHA-256 корпуса: `262fa5c26595c2b73f203991086074ec14e210aeae16055f764bde389dc94ca4`. Манифест источников и хешей: [corpus-manifest.json](benchmarks/corpus-manifest.json).

60 вопросов: 20 dev на 10 документах и 40 test на других 13 документах. Для каждого вопроса проверено существование опорного документа и точного текстового якоря. Вопросы и разметка составлены агентом, без независимой проверки человеком. Проверен один положительный документ; остальные документы не размечены исчерпывающе. Метрики показывают нахождение известного опорного документа, а не качество всех возможных ответов.

## Реальный benchmark

CPU Intel Core i5-1235U, 16 ГБ RAM, Windows, четыре потока PyTorch. Порог Laya 0.8 зафиксирован до запуска, по test не подбирался. Холодная загрузка записана отдельно; таблица показывает прогретый поиск, включая решение Laya. Во время запуска также шли Docker-сборки и отдельные smoke-запросы API: задержки являются наблюдением на этом ноутбуке, а не изолированным SLA.

Laya уверенно пропустила rerank в одном случае из 60. На dev обязательный rerank улучшил nDCG@5 одного вопроса; auto его не пропустил. На test полезных по этой метрике перестановок не было, поэтому отсутствие ошибочных пропусков не доказывает качество gate.

**Вывод:** пользы адаптивного rerank на этой выборке не обнаружено. Первичный поиск уже решает почти все опорные вопросы; Laya преимущественно оставляет rerank включённым и увеличивает задержку. Нужны более крупный корпус, трудные конкурирующие документы и независимая разметка. Порог и промпт не подгонялись под test. `auto` сохранён как запрошенный режим по умолчанию; `never` и `always` доступны для проверки гипотезы.

Если LLM не выдаёт корректные ссылки, приложение возвращает экстрактивные выдержки.

## Ограничения источников

Часть страниц Хабра завершилась таймаутом; параметр RSS `limit=100` оказался нестабилен и удалён. Часть страниц N+1 возвращает HTTP 403. Сборщик сообщает такие ошибки и сохраняет старые документы; ограничения доступа не обходятся. Викторина исключена из корпуса, поскольку её HTML-контейнер захватывал следующий материал. Повторная проверка некоторых страниц N+1 также дала 403; положительная проверка идемпотентности выполнена на доступной статье Хабра.

Полные сторонние тексты и веса моделей не публикуются в Git. Для точного повторения чисел нужен сохранённый том корпуса. Свежий сбор тех же URL может дать другой снимок.
