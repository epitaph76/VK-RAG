# Демонстрационная оценка поиска

`questions.jsonl` содержит 60 русскоязычных вопросов: 20 `dev` и 40 `test`. Вопросы составлены AI-агентом после чтения сохранённых текстов; человек их независимо не проверял. На `dev` приходится 10 документов, на `test` — 13 других документов. Документы между выборками не пересекаются.

У каждой записи есть `query`, тип вопроса, положительный `qrels`, ID опорного документа и короткий точный якорь `evidence` с символьными смещениями в очищенном тексте. Смещения отсчитываются с нуля, правая граница не включается. Проверено, что все якоря буквально присутствуют в сохранённых текстах.

В `corpus-manifest.json` записаны 23 исходных документа, их URL, заголовки, даты загрузки и SHA-256 очищенного текста. Общий `corpus_hash` совпадает с алгоритмом манифеста поискового индекса. Снимок собран 1 ноября 2026 года: восемь доступных статей Хабра и пятнадцать материалов N+1.

Начальные публикации N+1 получены через RSS; ещё шесть доступных статей найдены на главной странице. Для Хабра использована RSS-лента без параметра `limit=100`: восемь полных страниц успешно получены и очищены после исправления приоритетов HTML-контейнеров. Остальные двенадцать проверенных ссылок Хабра завершились сетевым таймаутом. Часть дополнительных ссылок N+1 вернула HTTP 403 и исключена без обхода ограничений. Медийная викторина N+1 исключена из-за попадания следующей статьи в общий HTML-контейнер.

Метрики нужно считать на одном замороженном корпусе и одинаковых вопросах для режимов `never`, `always`, `auto`. Для `auto` в задержку входит решение Laya, а не только поиск и reranker. Холодная загрузка моделей измеряется отдельно от прогретого поиска. Если порог Laya меняется, он подбирается только на `dev`; финальные результаты `test` не используются для подбора.

Ограничение разметки: проверен один положительный опорный документ для каждого вопроса. Остальные документы не размечены исчерпывающе. Поэтому Recall, nDCG и MRR характеризуют нахождение опорного документа, а не полноту всех потенциально релевантных источников. Это небольшой source-anchored benchmark для проверки реализации, не независимое доказательство качества в продакшне. Вопросы относятся к содержанию статей и не подтверждают фактическую достоверность публикаций.

Полные сторонние тексты и кеш моделей не включаются в Git. Для точного повтора результатов нужен сохранённый том `data`; повторная загрузка по URL может дать другой текст. Манифест позволяет обнаружить это по хешам.
